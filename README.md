# Pràctica 3 - GitHub Projects

**Projecte Intermodular - 1r DAM - Curs 2026/2027**

## Objectiu

Treballar de manera col·laborativa utilitzant Git, GitHub, GitHub Issues, GitHub Projects, Forks i Pull Requests.

## Descripció de l'activitat

Cada equip haurà de desenvolupar un lloc web sobre quatre sèries de televisió diferents.

Cada pàgina haurà d'incloure:
- Imatge de la sèrie.
- Sinopsi.
- Enllaç a IMDb.
- Estils CSS propis.

## Organització

1. Crear un repositori públic anomenat `intermodular03equipX`.
2. Crear l'estructura inicial: `index.html`, `README.md` i les carpetes `css`, `html` i `img`.
3. Afegir tots els membres de l'equip com a col·laboradors.
4. Crear un GitHub Project públic amb vista Kanban.
5. Donar accés d'administració al Project a tots els membres.
6. Crear issues per a les tasques i assignar responsables.
7. Organitzar el treball en `To Do`, `In Progress` i `Done`.
8. Treballar mitjançant forks i pull requests.
9. Actualitzar el README de l'equip amb els membres, la descripció, les tasques i els enllaços IMDb.

## Criteris de comprovació

- Repositori públic i estructura correcta.
- Quatre pàgines amb continguts i estils.
- Col·laboració de tots els membres.
